# Calculadoras de notas

Exercícios publicados no [Viking](https://github.com/vastlorD/viking), com implementações em Python e Node.js.

Recebem notas de 0 a 10, calculam média e apresentam aprovação a partir de 7. São projetos de estudo para praticar validação de entradas, funções e testes.
