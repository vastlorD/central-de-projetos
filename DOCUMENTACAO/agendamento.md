# Sistema de agendamento — Viking Art Tattoo

Projeto de sistema de organização de horários para o estúdio, pensado para tornar o atendimento mais prático.

O histórico descreve uma versão local com HTML e JavaScript, cadastro de clientes, agendamentos, prevenção de conflitos, relatórios e backup, com dados mantidos no navegador.

**Estado:** versão local relatada em conversa; código-fonte e testes não foram recuperados para esta conferência.

**Próximos passos:** recuperar os arquivos originais, validar conflitos de horários e backups, revisar privacidade dos clientes e só depois avaliar sincronização e integração com WhatsApp.
