# Boleto

O [repositório Boleto](https://github.com/vastlorD/boleto) contém um estudo em Python sobre consulta de dados em MySQL, geração de relatório PDF e comunicação via WhatsApp.

**Estado:** rascunho documentado, ainda não pronto para execução direta. O PDF descrito não é um boleto bancário registrado, e o envio não anexa automaticamente o arquivo.

**Próximos passos:** separar código e documentação, usar dados fictícios, configurar dependências, tratar erros e testar cada componente sem mensagens reais. Não publicar CPFs, credenciais ou dados de clientes.
