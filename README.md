# Central de Projetos

Este é o espaço onde reúno meus projetos de programação, automação e inteligência artificial. A ideia é mostrar não apenas o resultado, mas também o caminho: o que já funciona, o que ainda precisa melhorar e o que aprendi em cada etapa.

Nem tudo aqui está pronto. Alguns trabalhos têm código publicado e testes documentados; outros são protótipos ou planos que pretendo retomar. Prefiro deixar isso claro a prometer mais do que foi feito.

## Como este espaço é mantido

Os projetos originais continuam nos próprios repositórios. Esta central reúne documentação e acompanhamento, sem copiar dados pessoais ou segredos. Os resultados de testes anteriores são identificados como históricos até que sejam reproduzidos.

A organização da documentação contou com assistência de IA. O objetivo é manter um registro claro, acessível e fiel à evolução dos projetos.
