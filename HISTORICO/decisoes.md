# Decisões do projeto

- Manter uma central de documentação separada dos repositórios de código.
- Preservar Viking e Boleto sem mudanças durante a publicação inicial da central.
- Descrever com transparência os diferentes estágios de desenvolvimento.
- Usar linguagem simples e humana, sem exagerar funcionalidades ou resultados.
- Não copiar dados pessoais, credenciais nem arquivos privados para o GitHub.
- Registrar testes como históricos até que sejam reexecutados.
